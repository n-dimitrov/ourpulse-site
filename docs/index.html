Example session.

Set up once
  1. Install the plugin in Claude Code
    /plugin marketplace add https://ourpulse.click/marketplace.json
    /plugin install ourpulse@ourpulse
  2. Say "ask the team …"

    The first time, your browser opens. Sign in with Google and press Approve. There is no key to copy.

  3. Approve the draft

    Nothing is sent until you say yes. Then share the link or put the QR code on a screen.
