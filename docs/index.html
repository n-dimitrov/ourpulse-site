Ask the team without leaving Claude Code.

Install the plugin

/plugin marketplace add https://ourpulse.click/marketplace.json
/plugin install ourpulse@ourpulse

Then say ask the team … The first time, your browser opens: sign in with Google and press Approve. There is no key to copy.

What your team sees

A link or a QR code

Paste the link in chat and it unfurls with the title and closing time. Or put the full-screen QR on the meeting room TV.

One question per screen

Built for a phone. A five-question pulse takes about a minute.

No sign-in, no app

Answers are anonymous by default. Require Google sign-in when one answer per person matters.

Without an agent

Create a pulse by hand in about a minute and watch the results page live.
